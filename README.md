# Webpage — Protótipo de portfólio

Repositório de um protótipo antigo de site pessoal, feito com HTML, CSS e JavaScript nativo.

## Estrutura

- `web portifolio-prototype1/index.html`: página inicial.
- `web portifolio-prototype1/project.html`: página de projetos.
- `web portifolio-prototype1/app.js`: interações da interface.
- `web portifolio-prototype1/particles.js`: efeito de partículas.
- `web portifolio-prototype1/style.css` e `style-slid.css`: estilos.
- `web portifolio-prototype1/img/`: imagens locais.

## Arquitetura e execução

O navegador carrega as páginas estáticas e seus recursos locais. Não há framework, processo de build ou dependências npm identificadas. Abra `web portifolio-prototype1/index.html` ou sirva a pasta por HTTP.

## Estado

Este é um protótipo histórico, não o portfólio principal atual. Não há testes automatizados ou lint documentados. Confira os caminhos e scripts antes de reutilizar o código.
